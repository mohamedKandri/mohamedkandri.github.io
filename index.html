Encrypted file sharing

File sharing over a local network where every session gets its own key, and every file is checked before it is accepted

  • zero trust
  • hybrid cryptography
  • LAN
  • python
  • flask
  • pycryptodome
  • postgresql
  • architectureEach session gets a new AES-256-GCM key, wrapped with the recipient's RSA-4096 public key. File data uses authenticated encryption, so tampering is detected.
  • mitigationsMan-in-the-middle, replay and unauthorized access, handled with key rotation, HMAC validation and certificate pinning
