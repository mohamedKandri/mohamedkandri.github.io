🛡️ Zero-Trust Security 🔐 Hybrid Cryptography 🌐 LAN Architecture

Enterprise-grade secure file sharing with ephemeral key exchange and military-grade encryption

Security Architecture:

Hybrid RSA/AES model: RSA (4096-bit) encrypts ephemeral AES-256-GCM keys per session. All file data encrypted with authenticated encryption. Perfect forward secrecy implemented.

Tech Stack:

Python, Flask, PyCryptodome, PostgreSQL, TLS 1.3, JWT

Threat Mitigations:

Protection against MITM, replay attacks, and unauthorized access through strict key rotation, HMAC validation, and certificate pinning
