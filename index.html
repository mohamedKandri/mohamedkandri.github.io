Projects

Three systems where security was a requirement from the first design

Encrypted file sharing

File sharing over a local network where every session gets its own key, and every file is checked before it is accepted

  • focuszero trust · hybrid cryptography · LAN
  • stackpython · flask · pycryptodome · postgresql · tls 1.3 · jwt
architecture

Hybrid RSA and AES. Each session gets a new AES-256-GCM key, wrapped with the recipient's RSA-4096 public key. File data uses authenticated encryption, so tampering is detected.

stack

Python, Flask, PyCryptodome, PostgreSQL, TLS 1.3, JWT

mitigations

Protects against man-in-the-middle, replay and unauthorized access with key rotation, HMAC validation and certificate pinning.
